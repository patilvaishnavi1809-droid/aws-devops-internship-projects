# ☁️ AWS DevOps Internship Projects

This repository contains 5 hands-on AWS / DevOps projects completed as part of
the internship assignment. Each project lives in its own folder with its own
code, step-by-step guide, deliverables checklist, and a `screenshots/` folder.

## 📁 Projects

| # | Project | Key AWS/Tools |
|---|---------|----------------|
| 1 | [Elastic Beanstalk + RDS + EC2](Project-1-ElasticBeanstalk-RDS-EC2/) | Elastic Beanstalk, RDS, EC2, VPC |
| 2 | [EC2 Launch with Enforced Tagging Policy](Project-2-EC2-Tag-Policy/) | Organizations Tag Policies, SCP, EC2 |
| 3 | [3-Tier Infrastructure with Terraform](Project-3-3Tier-Terraform/) | Terraform, Ansible, VPC, EC2, RDS |
| 4 | [Docker → ECR → Jenkins → Lambda Pipeline](Project-4-Docker-ECR-Jenkins-Lambda/) | Docker, ECR, Jenkins, Lambda |
| 5 | [Flask Student Registration App](Project-5-Flask-Student-Registration/) | Flask, MySQL, HTML/CSS |

Each project folder README follows the same format:
- 🚀 Step-by-step guide
- ✅ Deliverable called out under every step (with a screenshot placeholder)
- 📂 Repository structure
- 🔐 Security considerations
- ✅ Final deliverables checklist

## 🖥 How to Use This Repository
1. **Clone it** (after you push it to your own GitHub, see below):
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open each `Project-X-.../README.md` and follow the steps on your own AWS account.
3. As you complete each step, drop your screenshot into that project's
   `screenshots/` folder and reference it from the README (the image links are
   already wired up — just add the actual `.png` files with matching names).
4. Commit and push your progress.

## 📤 Uploading This to GitHub
```bash
cd InternshipProjects
```
